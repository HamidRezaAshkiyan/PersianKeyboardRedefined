# Persian but Better v2.1 — Windows Installer

## Option 1: Standalone `.exe` Installer (Recommended)
1. Download **`PersianButBetter-<version>-Setup.exe`** from GitHub Releases and run it.
2. Sign out and sign back in.
3. Go to **Settings → Time & Language → Language & Region → Persian → Keyboard** and add **Persian but Better**.
4. To uninstall later, remove **Persian but Better Keyboard Layout** from **Settings → Apps → Installed apps**.

## Option 2: Portable ZIP (`setup.cmd`)
1. Extract this archive.
2. Right-click **`setup.cmd`** and choose **Run as administrator** (or double-click and accept the UAC prompt).
3. Sign out and sign back in, then add **Persian but Better** under Persian language options.
4. To uninstall, run `Uninstall-PersianButBetter.ps1` from an elevated PowerShell prompt.
