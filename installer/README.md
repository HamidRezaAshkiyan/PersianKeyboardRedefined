# Persian but Better v2.0 — Windows Installer

## Install
1. Extract this archive.
2. Right-click **`setup.cmd`** and choose **Run as administrator** (or double-click and accept the UAC prompt).
3. Sign out and sign back in.
4. Go to **Settings → Time & Language → Language & Region → Persian → Keyboard** and add **Persian but Better**.

## Uninstall
Run `Uninstall-PersianButBetter.ps1` from an elevated PowerShell prompt, then sign out and sign back in.
