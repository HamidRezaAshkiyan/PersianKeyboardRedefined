کیبورد فارسی آشنا، اما بی‌نقص‌تر

چیدمان حروف کیبورد کلاسیک فارسی ویندوز بدون تغییر عادت تایپ، همراه با اعداد فارسی در ردیف بالا، نیم‌فاصله استاندارد با Shift+Space، لایه کامل AltGr و پشتیبانی از ویندوز، مک و لینوکس.

نصب و دانلود تست زنده کیبورد

تست زنده و نقشه تعاملی کیبورد

در کادر زیر با کیبورد واقعی خود تایپ کنید یا روی کلیدها کلیک کنید. کلیدهای Shift یا Alt را نگه دارید تا لایه‌ها را زنده ببینید.

تغییرات و بهبودهای نسخه ۲.۰

رفع باگ‌های قدیمی ویندوز و افزودن قابلیت‌های تایپوگرافی مدرن بدون برهم زدن حافظه عضلانی شما.

FIX نیم‌فاصله واقعی (U+200C)

کلید Shift+Space اکنون به‌جای کاراکتر اشتباه ZWSP (U+200B)، نیم‌فاصله استاندارد ZWNJ (U+200C) تولید می‌کند تا کلمات وسط خط نشکنند و در جستجو پیدا شوند.

FIX اصلاح لیگچر «ریال» با «ی» فارسی

کلید Shift+R اکنون از «ی» فارسی (U+06CC) به‌جای «ي» عربی استفاده می‌کند و نماد اختصاصی ریال (﷼) نیز روی AltGr+R در دسترس است.

FIX بازگردانی میانبرهای Ctrl+0 و Ctrl+-

کاراکترهای مزاحم قدیمی روی Ctrl+0 و Ctrl+- حذف شدند تا میانبرهای Reset Zoom و Zoom Out در مرورگرها و ادیتورها بدون مشکل کار کنند.

NEW لایه کامل AltGr / Option

تایپ اعداد انگلیسی (0–9)، درصد فارسی (٪)، ممیز و جداکننده هزارگان (٫ ٬)، ساکن (ْ)، همزه بالای هـ (ٔ)، الف مقصوره (ٰ)، سه‌نقطه (…) و خط تیره (– —) بدون تغییر زبان.

راهنمای نصب

سیستم‌عامل خود را انتخاب کنید.

  1. نصب‌کننده آماده را از صفحه Releases دانلود کنید، یا فایل Better Persian.klc را در Microsoft Keyboard Layout Creator (MSKLC) باز کرده و از منوی Project → Build DLL and Setup Package خروجی بگیرید.
  2. فایل setup.exe را اجرا کنید و یک‌بار Sign out / Sign in انجام دهید.
  3. در بخش Settings → Time & Language → Language & Region → Persian → Keyboard کیبورد Persian but Better را اضافه کنید.
  1. فایل macos/Persian but Better.keylayout را دانلود کرده و در پوشه زیر کپی کنید:
cp "Persian but Better.keylayout" ~/Library/Keyboard\ Layouts/
  1. یک‌بار Log out / Log in کنید.
  2. از مسیر System Settings → Keyboard → Text Input → Input Sources → Edit… → + → Others گزینه Persian but Better را اضافه کنید. (کلید Option معادل AltGr است و میانبرهای Cmd مطابق QWERTY باقی می‌مانند.)
  1. فایل linux/persian-but-better.xkb را در مسیر XKB کپی کرده و فعال کنید:
sudo cp linux/persian-but-better.xkb /usr/share/X11/xkb/symbols/persian_better
setxkbmap persian_better better
